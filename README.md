# Cancer Awareness & Support Web Page

A simple, responsive web page built using **HTML** and **CSS** to promote cancer awareness and support. This project includes a landing banner and a contact form.  

---

## Features

- **Landing Page:**  
  Displays a banner image with a short awareness message.

- **Contact Form:**  
  - Name  
  - Email  
  - Message  
  (Static form; no backend integration.)

- **Responsive Design:**  
  Works well on mobile, tablet, and desktop screens.

---

## Technologies Used

- HTML5
- CSS3
- Flexbox for layout
- Responsive design with media queries

---

## Usage

1. Clone or download the repository.
2. Open `index.html` in any web browser.
3. Fill out the contact form (no backend, so form submission is not functional).
